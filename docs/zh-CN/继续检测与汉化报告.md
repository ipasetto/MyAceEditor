## 汉化审查覆盖与保留项

- 从界面、任务字段和属性文案中抽取并审查 290 项固定文字；审查范围内没有未处理的外文固定文案。
- 审查 170 个 CFG 中的 108,505 个不同原始字段键；485 个分类标签全部存在，显示字典无重复键。
- 另有 29 种参数代号或原始缩写需要保留，如 A/B/C、DPM、SPM、CLCT 等。它们不是已确认含义的业务词，未擅自解释；不明确的缩写显示为“原始标识（…）”，单字母参数代号保留原符号。
- 原始键、文件路径、ID、NPC、CFG、MPPC 等技术标识以及游戏数据中的名称、描述保持原样。汉化没有翻译或改写游戏内容。
- Windows 原生文件选择器的系统按钮由操作系统语言决定；本次补齐的是应用自有标题、说明和确认按钮。

审查清单：[固定界面文字](汉化固定界面.tsv)、[保留标识](汉化字段保留标识.tsv)、[机器可读汉化审查](汉化审查.json)。原审查脚本 `Tests/audit_localization.py` 已于 2026-10-29 删除（依赖的源文件已不存在；界面翻译现在位于 `lang/*.json`）。
