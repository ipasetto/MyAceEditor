# 读取进度与防卡顿说明

本版处理“读取时窗口无响应”和“读取结束后显示列表仍卡住”两段流程，继续使用原生 C#/.NET 10 WinForms，保留前版读取修复和中文界面。交付的是源码包，需要在 Windows 重新编译。

## 已实现的变化

| 原来的阻塞点 | 当前实现 |
|---|---|
| 界面线程匹配 CFG、解码全部记录 | 后台任务执行，进度窗口保持正常消息循环 |
| 首次绘制“被引用”数量时扫描全部字段 | 后台提前建立引用索引，绘制只查询缓存 |
| 每条记录重新判定引用、生成概率字段名 | 每个 CFG 数据块预编译引用字段与概率候选名 |
| 图标、描述和同目录任务在读取后同步准备 | 进入后台准备阶段，显示阶段名称 |
| 短时间大量进度报告 | 工作端限频，只保留最新状态，界面每 100ms 取样 |
| 字段、关联和任务控件一次填充 | 字段/关联每 128 行、任务每 256 行分批显示 |
| 初始化选择事件和连续搜索重复刷新 | 初始化事件保护及 180ms 搜索合并 |

## 如何使用

完整解压并运行 `build-zh-CN.cmd`，运行新生成的 `dist\MyAceEditor.exe`。打开 elements.data 后出现中文进度窗口：显示读取、匹配 CFG、解码、验证写回、ID/引用索引及附加资源阶段，并显示当前块、记录数或字节数和耗时。

进度按各阶段权重汇总，文件阶段由实际字节/记录推进；资源阶段总量未知时使用滚动条，不提供剩余时间估计。某一大型记录或资源处理期间百分比可能短暂停留。

点击“取消读取”、按 Esc 或关闭进度窗口，均请求取消。窗口会显示“正在取消读取…”，等待后台到达检查点后退出。操作系统正在进行的单次 I/O 或库调用不能强制中断。主窗口在读取期间暂时禁用；进度窗口持续显示状态并接受取消。

新数据及索引准备成功前不替换原会话。取消和后台准备失败会保留原来打开的元素及任务数据。自动找到的图标/描述/同目录任务如果加载失败，会在读取报告里附带提示；不将这些可选资源错误伪装成元素数据错误。

## 本次验证和限制

本环境没有 .NET SDK、Windows 或 Wine，**没有执行 C# 编译、C# 回归、WinForms 点击或性能测量**。以下已经运行的检查均明确区分方法：

- CFG 结构审查：170 个文件、164 个版本、42,866 个数据块；167 个无字段数量警告，另 3 个来源配置警告保留。
- 原始 CFG 指纹检查：170 个文件全部保持原字节。
- 独立 Python/C++ 参考回归：504 项检查通过，覆盖 170 个普通布局模拟文件和 71 个压缩布局模拟文件。
- 三个真实附件独立参考读取：v344 的 98,307 条记录、v386 的 105,892 条、v531 的 106,019 条全部读取至 EOF，共 10,255 个对话；v344 的参考重建与原字节一致。输入未修改。见 `读取进度版_参考读取.json`。
- 汉化源码审查：485 个分类、1,159 个词汇，298 项固定文字未发现未处理项；29 个含义未确认的原始缩写/参数保留。系统文件窗口按钮语言取决于 Windows。
- 36 个 C# 文件通过字符串/分隔符词法检查和人工调用路径审查。词法检查不是编译，也不证明实际界面不卡顿。

新增 C# 回归覆盖：提前取消 MPPC/资源包/DDS/任务；文件读取中取消后关闭句柄并保留输入；记录解码与写回校验取消传播；阶段进度单调；缓存查询不隐式建索引；取消时不发布部分引用索引；重新建立索引及概率值正确。这些案例需要在 .NET 环境执行。

## Windows 验收步骤

1. 双击 `build-zh-CN.cmd`，确认新增和原有 C# 回归通过，再确认发布成功。已有旧 EXE 不包含本次改动。
2. 分别打开 v344、v386、v531 样本。记录 Windows 实际耗时，确认各阶段更新、窗口可重绘，最终块数分别为 385/398/420，报告到达文件末尾；不要把独立参考读取耗时作为程序耗时。
3. 先打开一个正常文件，再打开较大文件，在解码和引用索引阶段分别取消；也测试 Esc 和关闭按钮。确认返回后原文件名、当前记录及未保存的内存修改仍在，取消不产生保存文件。
4. 打开错误或截断文件，确认错误提示可操作，原会话仍能使用。手选不完整 CFG 仍保持只读并显示未完整读取。
5. 如果存在 surfaces.pck/configs.pck/tasks.data，确认资源/任务阶段可取消。无这些资源时，确认元素读取仍可完成且旧游戏任务不会误留在新会话中。
6. 选择字段很多的配置块、含大量关联引用的物品和任务列表，连续切换选择与搜索；确认分批刷新期间窗口可响应，旧选择的迟到结果不会覆盖新选择。
7. 检查中文、125%/150%/200% 缩放与进度窗口遮挡。对普通可写样本先验证无修改字节一致，再用副本检查修改、备份和重读；压缩样本继续只读。

保存流程没有在本次改成异步，极端数据规模的内存压力和系统 I/O 仍可能影响响应。本版不承诺未验证的所有客户端版本都可读取，也不宣称已经测得提速倍数。
