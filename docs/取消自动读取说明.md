# 取消启动自动读取

启动时默认进入空会话，不再自动打开上次使用的 elements.data。

在 **文件 → 启动时自动读取上次文件** 中切换：未勾选表示取消自动读取；勾选表示下次启动自动读取上次文件。切换立即保存到本机，下次启动生效，不会因为勾选菜单而立即开始读取。旧版只保留了上次文件路径，升级后仍默认关闭自动读取。

开关关闭时，启动事件在查询上次路径和检查数据文件存在性前返回。上次路径仍可保留供以后主动开启使用。手动打开文件以及进度窗口的“取消读取”继续可用。`--snapshot` 诊断也遵循该开关。

本次只修改启动入口、菜单和文档，未修改解析或保存规则。源码字符串/分隔符和调用顺序静态审查通过；原有汉化审查通过，170 个 CFG 原始指纹不变。环境没有 .NET SDK 或 Windows，因此未编译或实际运行此开关。

Windows 验收：

1. 运行 `build-zh-CN.cmd`，编译并打开新程序；即使已有上次文件记录，也应停留在空会话。
2. 手动打开一个文件，关闭并重启；未勾选开关时应继续停留在空会话。
3. 勾选开关，关闭并重启；应显示上次文件的读取进度，仍可取消当前读取。
4. 取消勾选，关闭并重启；应停止自动读取。手动打开仍应正常。
