# MyAceEditor 中文使用说明

## 1. 打开数据

- **文件 → 打开游戏文件夹…**：选择包含 `element` 的游戏目录。
- **文件 → 打开 elements.data…**：直接选择元素数据文件。
- 程序会保存上次打开的路径，启动时默认不自动读取。通过 **文件 → 启动时自动读取上次文件** 可开启或取消，选择会保留到下次启动。
- 图标从 `surfaces.pck` 读取；颜色、描述及部分属性类型信息从 `configs.pck` 读取。缺少资源包时，对应图标或描述可能无法显示。
- 数据文件所在目录存在 `tasks.data` 时，程序会尝试自动加载；请将任务文件和所打开的元素数据放在同一目录中。

读取时会显示中文进度窗口，包含当前阶段、百分比、块/记录信息和耗时。点击“取消读取”、按 Esc 或关闭进度窗口可请求取消，等待当前检查点结束后返回；取消保留原来已打开的数据。资源总量未知时显示滚动进度，百分比不是剩余时间估计。

完成后状态栏显示数据块数和记录数。提示缺少某版本的 `.cfg` 时，需要匹配该数据版本的格式定义；不能将现有配置重命名来替代真正的版本适配。新版的后台读取及分批显示需要重新编译，尚未在本环境实际运行 Windows 界面，详见 [读取进度与防卡顿说明](读取进度与防卡顿说明.md)。

## 2. 元素数据

1. 在左侧选择数据块，例如“武器”“防具”“怪物”或“配方”。
2. 用类型筛选和名称 / ID 搜索缩小范围；启用跨块搜索可查找其他数据块。
3. 点击物品查看右侧字段。“全部”“基本”“需求条件”“攻击”等标签用于切换字段组。
4. 可保存的普通格式可以直接修改字段值；v386/v531 等压缩格式当前为只读。双击特殊字段可打开职业选择器或物品、怪物、配方、附加属性选择器。
5. 关联引用页显示其他记录对当前物品的引用；可点击可用链接跳转。
6. 使用“描述与颜色”查看游戏资源中的原始描述。

字段标签是显示用中文，鼠标停在标签上可查看原始字段键。原始字段键（例如 `require_level`、`file_icon`）和数值类型保持原样。概率字段的原始值通常为 0～1，提示中可显示为百分比；布尔字段仍按界面显示的 0 / 1 进行编辑。职业字段使用位掩码，推荐通过双击后的职业选择器修改。

## 3. 克隆、删除、批量修改和收藏

- 右键可新建、克隆、删除物品，或添加 / 取消收藏。
- 按 Ctrl / Shift 可多选，Ctrl+A 可全选当前列表。
- 右键“批量修改字段…”会将指定值应用于选中物品中存在的相应字段。
- 修改暂存在内存中，需要保存才会写回元素数据。

## 4. 任务

在“任务”页按名称或 ID 搜索，展开任务树查看子任务。v93 完整结构模式可编辑任务名称、标量字段、四组文本和对话。其他版本能否编辑完整结构，以实际界面的状态提示为准。

任务列表、子任务和对话每次显示最多200项，点击“加载更多”继续。选择任务时会显示字段准备状态；文本与对话在打开相应页签后显示，对话需要手动展开。连续搜索会合并短时间输入，并取消旧请求。此次为源码优化，尚未实际运行Windows程序，详见 [任务卡顿修复说明](任务卡顿修复说明.md)。

点击“应用名称”提交名称修改。文本框和对话框中的修改在离开字段后应用到内存。最后点击 **保存 tasks.data** 写入任务文件；元素数据的“保存”不能代替此操作。

游戏文本支持 `^RRGGBB` 颜色代码，例如 `^ffcc00`。游戏内换行使用 `\r`。不要改动任务 ID 等引用关系，除非已确认对应的数据关系。

## 5. 保存和备份

- **保存 / Ctrl+S**：任务页保存任务，其他页保存元素数据，并在覆盖前确认。
- **另存为…**：任务页另存任务，其他页另存元素数据。
- **保存 tasks.data**：单独保存任务。
- 覆盖已有文件时，程序在旁边创建带时间戳和唯一标识的 `.bak` 备份，连续保存不会使用同一个备份名。

保存期间显示后台进度并等待提交结束；随后重新读取时仍可取消。出现“磁盘已保存，界面重读未完成”时，文件已写入，可手动重新打开。错误提示中的阶段、路径和原始诊断用于定位权限、占用、空间或字段值问题。MPPC压缩元素文件仍为只读。新增保存流程尚未在本环境实际编译运行，详见 [保存失败修复说明](保存失败修复说明.md)。

客户端和服务端需要配套的数据文件。建议先对副本操作，验证后再用于实际游戏环境；自动备份不等于已经验证数据内容正确。

## 6. 一致性检查

在“一致性检查”页选择客户端的 `element` 文件夹和服务端的 `home` 文件夹，然后点击“开始检查”。服务端目录通常包含 `gamed`、`glinkd` 等子目录。

程序会比较元素、任务、商城及 AI 文件的部分头信息、地图副本和加密配置。说明栏解释每一项结果；此检查不覆盖所有游戏兼容问题。

## 7. 图标备用路径

自动读取图标失败时，可在“PCK 解包工具”页选择你已有的 `sPCK-GUI.exe`，用它解包资源后，再指定图标文件夹。压缩包没有附带 sPCK，也没有附带游戏资源。

## 8. MCP 与诊断命令

MCP 模式仍使用原命令：

```powershell
.\dist\MyAceEditor.exe --mcp
```

MCP 工具操作的是 JSON 模块，和图形界面中直接编辑游戏二进制数据的入口不同。工具名、参数名和 JSON 字段名保留原样，说明文字已翻译。

源码还提供 `--inspect`、`--roundtrip`、`--tasks`、`--check` 等诊断入口。可在副本上按原项目说明使用；本次处理未执行这些依赖真实游戏文件的检查。


## 多 CFG 适配更新

本次支持的配置范围、只读限制及新诊断命令见 [CFG 多版本说明](CFG_多版本说明.md)。打开后请查看状态栏采用的 CFG，并在“帮助 → 读取报告”中核对完整读取状态。仅有匹配的配置文件不能证明某个真实版本已验证。


## 真实文件读取修复

新增对压缩空列表和超过 8 KB 分段记录的处理，485 个数据分类已有中文显示名。v344/v386/v531 参考验证结果见 [真实文件验证报告](真实文件验证报告.md)。这是源码更新，需要 Windows .NET 10 SDK 重新编译；尚未生成新的 EXE。


## 汉化补全更新

查找字段、结果状态、文件窗口标题和应用确认按钮已补齐中文。字段提示保留原始键；含义不明确的扩展缩写标为“原始标识”，不会猜测含义。职业编辑窗口保留未显示的高位掩码。检测范围与 Windows 复核步骤见 [继续检测与汉化报告](继续检测与汉化报告.md)。
