# 保存功能复核

**结论：尚不能认定保存功能完全正常。** 本次继续审查发现下列源码遗漏并修补；已执行的检查是词法、引用和配置/文字审查。当前没有 .NET SDK、C# 编译器、Windows/Wine，也没有真实 tasks.data，未编译、执行 C# 文件保存回归或验证 Windows 界面。附带回归源码不等于测试已经通过。

## 本次发现与处理

| 源码路径与触发条件 | 原来的结果 | 当前处理 |
|---|---|---|
| TasksFile：名称模式改名保存，取消重读，再改回最初名称保存 | Data 已更新，OriginalName 仍是最初名称，生成时跳过改回操作 | 磁盘提交成功后才同步名称基线；失败仍保留原基线及修改 |
| TaskSchema/UI：编辑任务 ID、含签名或变长数据数量 | 固定原始字节与计数/解码密钥不一致，可能导致保存后结构损坏 | 18个结构字段记录原值；界面只读、Set 拒绝、Write 再核对；模型 ID 也核对固定头 |
| TasksFile：每个文件没有验证无修改重建完全一致 | 例如空 v93 文件附有尾部字节，重建会丢失尾部 | 读取完成先比较全部字节；未通过只允许查看，不开放保存 |
| TasksFile：异常任务偏移 | 名称头可能进入偏移表、相互重叠，或发生整数加法溢出 | 使用安全边界及重叠检查；异常文件只读，查看时跳过越界头 |
| QuestNode.Set：布尔输入不是明确真/假值 | 原来任何其他内容都静默写成0 | 明确识别1/0、true/false及兼容文字；其他输入拒绝。网格验证失败保留编辑并阻止保存 |
| QuestNode.Get / CellEndEdit：浮点值仅显示小数点后6位 | 很小的值显示为0；进入编辑后未改内容也可能写回精度较低的值 | 改用可往返的R格式；未改显示值不重写，保留NaN等原始位 |
| TaskSchema.EncodeTexts：程序传入超长固定对话标题或选项 | 超过63个UTF-16单元被静默截断 | 编码阶段明确拒绝；界面原有63长度限制继续保留 |

结构字段指会改变文件布局或任务解码密钥的字段；普通需求、时限等已支持标量仍可修改。完整任务结构仍仅支持 v93；其他版本保持名称模式。无修改字节一致仅证明该文件可无损重建，不表示任意修改都符合游戏逻辑。

## 保留的写入流程

元素与任务都先在后台生成字节，再用 AtomicFileSave 在目标同目录写入唯一临时文件，Flush(true)后逐块回读比较；覆盖前创建唯一备份，再替换目标。编码错误发生在磁盘提交前；磁盘失败保留编辑，临时文件尽力清理。错误显示具体字段，或写入、校验、备份、替换阶段与路径。

临时文件回读只验证它与生成字节一致。尚未实测的文件系统替换行为、断电情况和游戏端兼容性不在当前结论之内。提交保存时不可取消；保存后的界面重读可取消，两者分别显示状态。取消重读可能保留待保存标记，应以磁盘重开结果核对。

**MPPC压缩元素仍只读，包括已提供的v386/v531样本；未完整读取、有CFG警告或无修改往返失败的元素也只读。** 本次没有实现压缩保存。

## Windows验收

1. 在解压目录运行 `build-zh-CN.cmd`。它先执行 `Tests/CfgRegression`，失败则停止发布；成功后才生成 `dist/MyAceEditor.exe`。保留 `cfg-regression-result.txt`。本环境没有代为执行。
2. 在副本上测试元素编辑、新建/克隆/删除、另存为与重开；核对目标字段和未修改字段，确认唯一备份内容是保存前版本。
3. 打开任务文件，在对应页直接编辑后按Ctrl+S、连续保存及另存为；确认任务文件目标正确。保存后取消重读，再改回最初任务名保存并重开核对。
4. 确认任务ID和变长结构字段只读；普通布尔输入非法文字时不应默默变成0，也不应继续保存。小浮点值在进入和退出编辑后应保持数值及原始位。
5. 修改合法任务名称、标量、文本、对话后保存重开；对超长名称/固定对话、异常偏移或往返不一致文件，确认禁止保存且目标副本不变。
6. 独占占用目标或使用无写权限目录，确认明确报错并保留内存修改，再使用可写目录另存为；取消后续重读应提示磁盘已经保存。完整真实任务的游戏端验收仍需客户端/服务端配套数据。

这些项目在Windows和真实任务文件上完成之前，结论保持“源码遗漏已修补，运行验证待完成”。
