**MyAceEditor — update (October 24, 2026)**

Hey everyone! Quick update on MyAceEditor, the open-source Perfect World data editor (C# / .NET, GPL-3.0): https://github.com/ipasetto/MyAceEditor

A lot happened since my last post. Highlights:

- **GShop editor with the real in-game shop window.** It reads qshop.xml from your interfaces.pck and the textures from surfaces.pck, so you edit the shop on the same screen players see. Double-click a name, a price or a category to edit it right there. Saving writes gshop.data (client) and gshopsev.data (server) together with the same timestamp. Undo/redo included.
- **Interface editor (inside the PCK extractor).** Open any .pck that has windows and click "Edit interfaces": the 533 windows from interfaces.pck are drawn like in the game, with the client's own fonts. Click a control, drag to move, drag the corner to resize, double-click to change the text. Unchanged files are written back byte-for-byte; only what you touched changes.
- **Client × server check that fixes itself.** It shows what would make the login fail ("wrong version": elements/tasks version, shop timestamp…), and a "Fix" button rebuilds the server side from the client, with a backup of every file.
- **Find errors** (Ctrl+E): IDs that don't exist, probabilities outside 0–100% or not adding up to 100%, duplicate IDs (per ID space, like the game does). Probability fixes are one click.
- **Undo/redo + action history**, and **bulk change** (set, add, multiply, sequence, random, replace text) with a before/after preview.
- **Tooltips like the game** (monster stats, drops with icons, who uses the item), weapon/armor types now list their subtypes and items, and monster codes are explained (combat type, aggressive, land/water/air, seconds per hit).
- **Native PCK extractor** (no sPCK needed): preview images and text, extract to `<pack>.files` like sPCK does.

Thanks to everyone who shared knowledge here over the years. Feedback and bug reports are very welcome!
